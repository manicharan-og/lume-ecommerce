Privacy Policy.

How the current LUMÉ project handles account, shopping and technical information.

LAST UPDATED · 8 SEPTEMBER 2026

ON THIS PAGE

Information we handle

When you use account or checkout features, LUMÉ may handle information you provide such as your name, email address, phone number, saved delivery addresses, cart, wishlist and order information.

Browser storage

The website may use browser storage for guest cart data, wishlist data and recent searches so that basic preferences can remain available between visits.

Firebase services

Authentication and application data are currently supported by Google Firebase services, including Firebase Authentication, Cloud Firestore and Firebase Hosting. Those services may process technical information necessary to provide the website.

Payment information

The current LUMÉ project uses a mock payment interface. Card number and CVV data are not stored in Firestore by the current application. A real store must use a compliant payment provider and must never store sensitive card credentials in frontend code or Firestore.

Security

Reasonable technical safeguards are used for the project, including authentication and Firestore security rules. No internet service can guarantee absolute security, and production deployment should move sensitive order and stock operations to trusted server-side code.

Your choices

You can update profile information and saved addresses from your account where those controls are available. For requests relating to account information, use the contact details published by LUMÉ once a production support channel is established.
