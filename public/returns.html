Returns & Cancellations.

Information about the current cancellation and return experience.

LAST UPDATED · 8 SEPTEMBER 2026

ON THIS PAGE

Return eligibility Order cancellation Refunds Before commercial launch

Return eligibility

The current project describes eligible unworn items as returnable, but a final commercial return window and condition policy have not yet been configured.

Order cancellation

The current My Orders feature can cancel eligible orders while they are in early order states such as Placed or Confirmed. Stock is restored in the application when an eligible cancellation succeeds.

Refunds

The current website does not process real payment refunds. A production store must connect refund handling to its payment gateway and define when refunds are approved and how long they take.

Before commercial launch

Set a clear return window, non-returnable categories, exchange policy, reverse-pickup process, refund timeline and customer support channel before accepting real purchases.
